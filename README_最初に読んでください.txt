ND_Game01 完成版Unityプロジェクト
================================

対象Unity: 6.3 LTS (6000.3.11f1)

【開き方】
1. ZIPを右クリックして「すべて展開」します。
2. Unity Hubを開き「Add」または「プロジェクトを追加」から、解凍した ND_Game01_FullProject フォルダを選びます。
3. Unity 6.3 (6000.3.11f1) で開きます。
4. 初回インポート後、Assets/Scenes/Main.unity が自動生成されます。
   自動生成されない場合は、上部メニュー ND_Game01 > セットアップ > ゲームシーンを再作成 を選びます。
5. Main.unity を開き、上部中央の ▶ を押して再生します。

【操作】
・マウス移動：自機を移動
・左クリック：通常弾を発射
・敵弾が近づく：最大5個まで自動キャッチし、自機の周囲を公転
・右クリック：キャッチした弾をボス方向へ一斉に投げ返す
・投げ返した弾：ボスに40ダメージ
・通常弾：ボスに8ダメージ

【提出用ビルド】
このZIPはUnity Editorで開くためのプロジェクト一式です。Windows実行ファイル(.exe)は、Unity Editorで動作確認後、File > Build Profiles からWindows向けにビルドしてください。
